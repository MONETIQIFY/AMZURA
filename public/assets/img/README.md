# Where to put your images

Drop your real files here with these EXACT names and the site picks them up automatically. Until then, the site shows clean text/graphic fallbacks so nothing looks broken.

| File name (put it in this folder) | Used for |
| --- | --- |
| `logo.png` | The AMZURA logo (transparent PNG best). Shows in the header + footer. |
| `logo-emblem.png` | *(optional)* Just the round emblem, if you want it separate. |
| `og-image.jpg` | Social share preview (1200×630) when the link is pasted in DMs/socials. |
| `testimonials/win-1.jpg` | Student win screenshot #1 (e.g. the £30k Lambo one) |
| `testimonials/win-2.jpg` | Student win screenshot #2 (e.g. the £15k Audi R8 one) |
| `testimonials/win-3.jpg` | Student win screenshot #3 (e.g. the £600 one-product one) |

## How to add them (easiest way)
1. On GitHub, open this folder: `public/assets/img/` (and `public/assets/img/testimonials/`).
2. Click **Add file → Upload files**, drag your images in, name them as above, **Commit**.
3. Netlify redeploys automatically in ~1 minute. Done.

> Tip: keep each screenshot under ~500 KB so the page stays fast. Any phone screenshot is fine.
